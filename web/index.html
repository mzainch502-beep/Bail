WELCOME TO BAIL

Make ideas move.

Write a short story, pick a direction and compose. Select any scene to change its text, length or photo. Preview, then export.

Install on your phone

Android: open in Chrome → menu → Add to Home screen. iPhone: open in Safari → Share → Add to Home Screen.

What’s free?

Motion graphics, photo animation and browser export run on your device. AI cinema needs your own ComfyUI server and video workflow. No AI model or free GPU service is bundled.

Export format depends on your browser (WebM or MP4). Keep Bail in the foreground during export. Some mobile browsers don’t support recording.

Your space, your files.

Motion projects, images and music stay in this browser. No analytics, account, ads or tracking. GitHub serves the app and may log network requests according to its policies.

AI prompts and workflows are sent only to the ComfyUI server you connect. The connection address and workflow stay in this browser session. Never connect an untrusted server or put credentials in a URL.

Saved projects use browser storage, which may be cleared. Export a JSON backup for important work. AI footage is downloaded separately and is not included in project backups.

AI CINEMA / COMFYUI

Bring your own model.

Connect an HTTPS ComfyUI server you control, with the video model already installed. Use an API-format workflow containing {{prompt}} in its positive prompt text. Optional {{negative}} and {{seed}} placeholders are supported.

Your server must allow this app’s origin through CORS. Plain HTTP is accepted only when Bail itself runs locally. Don’t expose an unauthenticated GPU server publicly. Camera/style controls above apply to motion graphics, not to your ComfyUI workflow.
